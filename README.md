# ISTQB® CTFL® v4.0 — Practice Exam 5

40 questions with detailed explanations. Free, independent study resource by Kadir Çamoğlu, aligned with the ISTQB® CTFL Syllabus v4.0.1 and Exam Structure Tables v1.18.

**Status: public draft.** Independent review and finding closure are complete. Questions and explanations may change.

- Exam: https://kadir-camoglu.github.io/istqb-ctfl-v4-0-1-mock-exam-5-en/
- Companion guide: https://kadir-camoglu.github.io/istqb-ctfl-v4-exam-guide/
- Feedback: kadir.camoglu@gmail.com

Open `index.html` in a browser. The exam works as a standalone file and needs no installation.

Exam mode offers 60 minutes, 75 minutes or no timer, with feedback after submission. Study mode offers per-question feedback and links to the guide. Question order, progress, flags and theme are saved in the browser on the same device. Nothing is sent to a server. Results include chapter scores, explanations and a mistake-log CSV. Printing with and without answers is available. One question asks for two selections; it earns its point when both correct options and no incorrect option are selected.
